# 🎓 Student Attendance Management System

A full-stack **web application** designed to manage student attendance efficiently using  
**Spring Boot**, **Hibernate (JPA)**, **MySQL**, and **Angular**.  

This project allows teachers/admins to manage students, courses, and attendance records in a digital and user-friendly way.

---

## 🚀 Features

### 👩‍🏫 Admin / Teacher
- Add, update, and delete students  
- Create and manage subjects or courses  
- Mark daily attendance for each student  
- View attendance reports by date, course, or student  
- Manage users (teachers, admins)  

### 🎓 Student
- Login and view personal attendance  
- Check attendance summary and daily status  

---

| Layer | Technologies |

| **Database** | MySQL |
| **Tools / IDEs** | Eclipse (Backend), VS Code (Frontend) |
